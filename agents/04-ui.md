# agents/04-ui.md

## V2 only — never embeds

All user-visible output uses Discord Components V2 (serenity `next` branch).
Never use `CreateEmbed`, `Embed`, or any embed-related builder. The entire TS
lumi UI surface maps to V2 containers/cards/panels.

## Builders (crates/ui)

```rust
// crates/ui/src/card.rs — primary output primitive
pub enum CardKind { Info, Success, Warning, Error, List }

pub struct CardOptions {
    pub title: String,
    pub description: String,
    pub kind: CardKind,
    // …fields matching TS CardOptions
}

pub fn make_card(opts: CardOptions) -> CreateActionRow { … }
pub fn make_list_card(title: &str, items: &[String]) -> CreateActionRow { … }

pub struct CardReply;
impl CardReply {
    pub fn reply(ctx, opts: CardOptions) -> impl Future<…>;
    pub fn message(opts: CardOptions) -> CreateMessage;
}
```

Match the documented card layout exactly. When in doubt, follow the builder signatures above.

## Snapshot tests

Use `insta` to snapshot-test the JSON output of card builders so output
regressions are caught. Add tests in `crates/ui/src/tests/`.

## Panels / layout

`crates/ui/src/panel.rs` — containers, separators, input components.
Keep the module self-contained; no serenity gateway types (only builder types).
