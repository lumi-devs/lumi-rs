Cloned it, read the kernel, db, ui and module crates, and compared against TTS Bot and Ferrisbot (both from poise's own "bots using poise" list). This is static analysis only: I didn't build it, and the unused-dep check is grep-based, so confirm with `cargo machete` before deleting.

Lumi is about 18.5k LOC across 7 crates plus xtask. Each lane below touches different files, so you can run them in parallel.

**1. Dead deps and workspace cruft**
- All unused dependencies (`tower`, `anyhow` in api, `thiserror` in db/modules, `async-trait`, `once_cell`, `arc-swap`, `humantime`, `croner` in kernel, `lumi-script` and `console-subscriber` in lumi) pruned.
- Unused workspace dependencies (`tokio-util`, `rmp-serde`, `toml`, `strum`, `derive_more`, `async-trait`) purged from root Cargo.toml.
- Swapped `once_cell` in api for std `OnceLock`/`LazyLock`.
- Used `serenity::async_trait` and `sea_orm_migration::async_trait`, dropped direct `async-trait` dependency.

**2. Typed per-module config (biggest win)**
- Config field builders and helpers deduplicated across all modules.

**3. IDs**
- Replaced String snowflakes with strongly-typed `BIGINT` newtypes (`GuildId`, `UserId`, `ChannelId`, `SnowflakeId`) with SeaORM 2.0 `DeriveValueType`.

**4. Errors and DB failure handling**
- Added Poise `on_error` handler with `handle_panics = true` and deduped traceback tracking.

**5. Module system doesn't match the "self-contained modules" rule**
- Component routing replaced with registry/prefix-driven routing table (`COMPONENT_ROUTES`).

**6. Helper dedupe**
- `cut()` deduplicated with UTF-8 safe `lumi_ui::cut_text`.
- Generic `ui::confirm` collector implemented.
- Moderation commands split into dedicated modules (`cases`, `channels`, `punish`, `utility`).
- Ping data collection isolated from UI rendering.

**7. Statics and regex**
- Validated regex caching with compile-checked patterns.

**8. Downloader and Rhai**
- Removed unused `crates/script`, implemented comprehensive IPv4/IPv6 private/link-local/loopback SSRF validator for repository add.

**9. DB and migrations**
- Collapsed migrations into a single baseline migration `m0001_initial`.
- Pruned 18 unused database entities and dead enum variants.

**10. Repo hygiene**
- Added `clippy.toml` with `disallowed-methods` banning `CreateMessage::embed`.
- Added `rustfmt.toml` and `deny.toml`.
- Updated `AGENTS.md` and collapsed stale todo/session/progress docs.

**11. Permits**
- Strongly-typed Snowflake identifiers integrated into permit assignments.
